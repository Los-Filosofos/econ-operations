# Siluetas del grafo operativo

Los archivos `graph-*.svg` son recursos originales y locales de ECON. Se
dibujaron como siluetas planas para el grafo operativo y no incorporan imágenes
generadas ni material de terceros.

La vista selecciona `excavator`, `loader`, `roller` o `truck` únicamente cuando
`equipment_class` contiene información suficiente. En cualquier otro caso usa
`graph-machinery.svg`. Los iconos de proyecto, base y taller no autorizan crear
lugares: sólo se renderizan cuando el modelo normalizado aporta esa identidad y
clasificación.

La portada usa Roboto Mono Variable, distribuida localmente bajo SIL Open Font
License 1.1. El texto completo está en `RobotoMono-OFL.txt`.
